# Agent instructions

- Use Conventional Commits for commit messages: `<type>(<optional scope>): <description>` (for example, `fix(tui): improve muted text contrast`).
- Include a `Co-Authored-By: Name <email>` trailer crediting the assisting agent in every agent-assisted commit. For Codex, use `Co-Authored-By: Codex <noreply@openai.com>`.
